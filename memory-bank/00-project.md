# 云枢 (CloudPivot IMS) — 项目全景与业务约束

## 1. 核心愿景与产品定位

为越南中小型家具生产工厂打造一套 **轻量级桌面端进销存管理系统**，覆盖采购→生产→销售→库存→财务全链路，支持中/越/英三语与 VND/CNY/USD 三币种。

- **中文名**：云枢
- **英文名**：CloudPivot IMS (Inventory Management System)
- **标识符**：`com.cloudpivot.ims`

## 2. 12 大功能模块

1. **基础数据**：物料 / 分类（树形）/ 供应商 / 客户 / 仓库 / 单位
2. **BOM 管理**：多级物料清单 / 反查 / 需求计算 / 成本核算
3. **采购管理**：采购单 → 入库（批次 + 费用分摊）→ 退货（成本回调）
4. **销售管理**：销售单（行折扣 + 整单折扣率）→ 出库（FIFO + 双成本快照）→ 退货（成本回调 + 应收冲减）
5. **库存管理**：实时库存查询 / 出入库流水 / 自由出入库（草稿 + 原子过账）/ 盘点 / 调拨
6. **定制单管理**：配置明细 / 定制 BOM / 预留释放 / 报价 / 转销售 / 转生产
7. **生产工单**：领料出库 / 退料入库 / 完工入库（含成本核算）
8. **智能补货**：策略配置 / 建议计算 / 消耗趋势 / 一键生成采购单
9. **财务辅助**：应付账款 / 应收账款 / 付款收款登记
10. **报表中心**：采购 / 销售 / 库存（收发存 / 库龄 / 滞销 / 趋势）+ Excel 导出
11. **系统设置**：企业信息 / 显示偏好 / 编码规则 / 库存规则 / 汇率 / 打印 / 数据管理 / 操作日志 / 用户管理
12. **认证与权限**：多账号 / admin·operator·viewer 三角色 / 模块×操作二维权限矩阵

### 范围边界

- **是**：业务单据、库存、报表、打印和简易应收应付。
- **不是**：专业财务软件、越南法定税务/发票系统。

## 4. 行业背景与越南工厂特殊约束

### 行业背景

- **原材料种类繁多**：木材（实木、板材）、五金配件、油漆涂料、布艺皮革、玻璃、包装材料
- **半成品/成品两级库存**：毛坯件、组装件等半成品形态
- **BOM 刚需**：一件成品家具由数十种原材料组成，需精确管理用量和损耗率
- **批次追溯**：木材含水率、板材甲醛等级需按批次追溯
- **定制化生产**：非标定制单是日常业务
- **跨国供应链**：供应商来自越南本地、中国、马来西亚等地

### 越南本地约束

| 维度 | 约束 |
|------|------|
| 货币 | VND（日常）/ CNY（中国供应商）/ USD（出口），金额统一以最小货币单位 INTEGER 存储 |
| 语言 | 中文 / 越南语 / 英文 三语切换，工厂管理层可能是中方/越方人员 |
| 税务 | MST（Mã số thuế）税号，增值税率与中国不同 |
| 地址 | 省 → 市/县 → 坊/社 → 街道 |
| 电话 | 国际区号 +84，手机号 10 位 |
| 时区 | UTC+7（Ho Chi Minh），数据库连接统一设置 |

## 5. 核心用户流

### 采购流程
```
供应商管理 → 创建采购单 → 审核 → 入库确认（批次+费用分摊）→ 应付账款 → 付款登记
                                  ↘ 退货确认（成本回调）→ 应付冲减
```

### 销售流程
```
客户管理 → 创建销售单 → 审核 → 出库确认（FIFO+双成本快照）→ 应收账款 → 收款登记
                                ↘ 退货确认（成本回调+应收冲减）
```

### 定制 & 生产流程
```
定制单 → 配置BOM → 预留库存 → 转生产工单 → 领料 → 生产 → 完工入库 → 转销售单
```

### 库存管理流程
```
库存查询（四维筛选+预警） → 盘点（实盘录入+审核） → 调拨（双仓选择） → 自由出入库（草稿+过账）
                          ↗ 出入库流水（多维筛选+来源区分）
```

### 智能补货流程
```
策略配置 → 系统计算建议 → 审批/忽略 → 一键生成采购单
```

## 6. 交互逻辑要点

- **桌面端优先**：Tauri 原生窗口，默认最大化，最小 1024×768。
- **列表页统一骨架**：`BusinessListTableShell` + 表头吸顶 + 首列 sticky + 分页吸底。
- **编辑/详情统一 Dialog**：不用 Drawer/Sheet，统一 Dialog 弹窗。
- **日期选择**：带弹出日历的 DatePicker，列表页用日期范围选择器。
- **紧凑视图**：外观设置可切换紧凑列表视图，全局生效。
- **权限驱动 UI**：菜单和按钮按角色权限自动隐藏。
- **Toast 提示**：统一使用 Sonner，不手写 Toast。
- **橡皮筋回弹已禁用**：接近原生桌面体验。
- **自动更新**：启动后自动检查，关于弹窗提供手动检查入口。

## 7. 数据与系统安全约束

- SQL 查询全部参数化，禁止字符串拼接。
- 库存操作使用 `FOR UPDATE` 行锁。
- IPC 权限守卫逐步补齐中：认证/用户管理/打印/自由出入库已有 `require_permission` 校验，其余 16 个命令文件的守卫在权限重构批次 4 补齐。
- 用户管理类命令需 admin 角色。
- 认证会话文件 Unix 0600 权限。
- 日志不记录密码、证件号等敏感信息。
